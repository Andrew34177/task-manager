# Task Manager

## Описание

Task Manager — это небольшое веб-приложение для управления личными задачами. Проект написан на чистом HTML, CSS и JavaScript, без использования сторонних библиотек. Данные хранятся в JSON-файле.

## Назначение

Приложение помогает пользователю вести список задач. Можно создавать новые задачи, просматривать их, отмечать выполненными и удалять. Всё просто и понятно, без лишних настроек.

## Возможности

- Создание новых задач
- Просмотр списка всех задач
- Отметка задачи как выполненной
- Удаление выполненных задач
- Хранение задач в JSON-файле

## Технологии

- HTML — структура страницы
- CSS — оформление интерфейса
- JavaScript — логика работы приложения
- JSON — хранение данных

## Требования

Для запуска нужен только современный браузер и локальная копия проекта. Никакие дополнительные библиотеки устанавливать не нужно.

## Запуск

Открой файл `src/index.html` в браузере.

## Структура проекта

task-manager/
├── src/
│   ├── index.html
│   ├── style.css
│   └── app.js
├── data/
│   └── tasks.json
├── screenshots/
│   └── main.png
└── README.md


Описание файлов:

- `src/index.html` — основная страница приложения
- `src/style.css` — стили и оформление
- `src/app.js` — логика работы с задачами
- `data/tasks.json` — файл, где хранятся задачи
- `screenshots/main.png` — скриншот интерфейса
- `README.md` — документация проекта

## Данные

Все задачи хранятся в файле `data/tasks.json`. Пример структуры:

```json
[
    {
        "id": 1,
        "title": "Подготовить документацию",
        "completed": false
    }
]
